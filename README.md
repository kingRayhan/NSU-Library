## Run with Gradle

From the project root directory:

```bash
./gradlew run
```

## Build with Gradle

```bash
./gradlew clean build
```

## Notes

- Main class: `info.rayhan.nsu_library.App`
- Source and resources are both under `src/`
- SQLite database file is `src/database/library.db`
